# GPIO + TIM：从 0x40020800 到 1ms 时基

- 日期：2026.11.01 – 11.03
- 实际投入：约 14 小时（估）

## 要解决什么问题
不查库函数，用寄存器点亮 LED、读按键、建 1ms 时基。

## 踩的坑
### 坑 1：`MODER &= ~(11 << 26)` 行为异常
- 现象：引脚模式改成了别的
- 根因：`11` 是十进制 = 二进制 `1011`，不是 `0b11`
- 教训：用 `3U` 或 `0b11`，永远别写 `11`

### 坑 2：`OTYPER &= 0 << 13` 清空了整个寄存器
- 现象：所有引脚输出类型都变了
- 根因：`0 << 13` 等于 0，等于"把寄存器清零"
- 教训：清一位用 `&= ~(1U << n)`，**`~` 不能省**

### 坑 3：LED 第一次翻转"没反应"
- 现象：第一次不对，后面都对
- 根因：`is_on` 逻辑状态与上电实际电平不一致
- 教训：**Init() 里显式 Off()，不依赖复位默认值**
- 通用规律：凡是"第一次不对、后面都对"，先怀疑初值

## 关键数字
- TIM2 挂 APB1 = 42MHz，定时器时钟 = APB1 × 2 = 84MHz
- PSC = 83 → 1MHz → 1 计数 = 1µs
- ARR = 999 → 1000 × 1µs = 1ms
- `EGR = UG` 让 PSC/ARR 立即装载
- `SR` 是写 0 清除，不是写 1 清除

## 验证
用手机秒表数 6 次 LED 翻转 = 60 秒。
