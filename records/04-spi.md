# 硬件 SPI：一个字节都不通，但寄存器"看起来都对"

## 四个坑（全部表现为"不报错、只是不通"）
### 坑 1：MOSI 被配成了输入
`MODER &= ~(3U << 14)` → 00 = 输入。MOSI 是主机输出，必须 10。

### 坑 2：MODER 设了复用，但 AFR 没配
**这是最隐蔽的一个。** `MODER = 10` 只表示"复用"，
复用什么由 `AFR` 决定，默认 AF0(SYS) ≠ AF5(SPI1)。
漏了 AFR = 引脚没接到外设，现象和"外设坏了"一模一样。

### 坑 3：BR 被 &= ~ 清零 → 42MHz
`CR1.BR` 复位值 000 = fPCLK/2。杜邦线上跑 42MHz 不可靠。
先 /256 = 328kHz，通了再往上加。

### 坑 4：Start/Stop 逻辑反了
SPI 片选低有效。Start 应拉低（选中），Stop 应拉高（释放）。

## 关键配置
- PA5/PA6/PA7 → AF5；PA8 = CS 推挽输出
- SSM=1 + SSI=1（软件 NSS），否则 MODF 静默停机
- 模式 0（CPOL=0, CPHA=0），8bit，MSB first

## 验证
读 W25Q 的 JEDEC ID = EF 40 17 → 实测是 W25Q64（8MB），不是 W25Q32。
